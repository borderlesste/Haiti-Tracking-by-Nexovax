## gps-locating.webp / gps-locating.lottie
- Created 2026-11-14 with the connected LottieFiles Creator native API.
- Document: haiti-tracking-gps-locating, revision 1.
- 96×96 pixels, transparent background, 24 fps, 2 second loop.
- Native ellipse/rectangle shapes and keyframes, blue target with red position dot and expanding locating pulse.
- WebP rendered export used by the site without a player dependency; dotLottie retained as editable animation source.
- Intended only for the pending GPS state. Respect reduced-motion preferences in the consuming UI.
